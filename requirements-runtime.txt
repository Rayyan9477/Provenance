# Runtime dependency set — what a *serving* container installs.
#
# Why this file exists
# --------------------
# Before it, `[project] dependencies` was empty and every runtime import lived
# in the `dev` extra beside aws-cdk-lib, mutmut, pytest, boto3 and anthropic.
# Two consequences, both measured on this tree:
#
#   1. A clean clone following README step 1 (`make bootstrap`) installs no
#      fastapi, no uvicorn, no pydantic, no google-genai and no mcp. Every one
#      of them was present on the build machine only because it had been
#      installed by hand. The README promises spin-up instructions, and the
#      instructions did not produce a runnable process.
#   2. A container built from `.[dev]` would ship the AWS CDK and the whole test
#      toolchain into a serving image.
#
# The list is duplicated in `[project.optional-dependencies].runtime` so that
# `pip install .[runtime]` and `pip install -r requirements-runtime.txt` agree,
# and `tools/tests/test_runtime_requirements_match_pyproject.py` fails if they
# ever stop agreeing. That test is the reason two copies are safe here and were
# not safe for the dev set, which `requirements-dev.txt` resolves through
# `-e .[dev]` rather than restating.
#
# Pins are exact. A serving image whose dependency versions depend on the day it
# was built is not a reproducible artifact, and the one thing a reader can check
# about a deployment is that it is the same thing as the repository.
#
# What is deliberately NOT here
# -----------------------------
#   boto3, botocore   lazily imported inside app/retrieval/embeddings.py for the
#                     Titan path only. The pivot discarded that path; the import
#                     stays reachable because the 18,035 corpus vectors are Titan
#                     output and stay uninterpretable without it. A serving
#                     container never re-embeds, so it never reaches the import.
#   pyarrow           lazily imported in the same module for the parquet vector
#                     cache, which is a seed-time concern. 40 MB of wheel for a
#                     code path a request never takes.
#   anthropic         superseded by the Gemini canon.
#   alembic           migrations run as pv_migrator from an operator machine,
#                     never from a serving container. A container that can
#                     migrate is a container that can drop a column.
#   sqlalchemy-*      alembic's, and alembic is not here.

# --- web framework and server -------------------------------------------------
fastapi==0.128.0
starlette==0.41.3
uvicorn==0.40.0
# FastAPI parses multipart form bodies through this; artifact upload (8.18) is a
# multipart route, and without it FastAPI raises at import of the route module
# rather than at the first upload.
python-multipart==0.0.20

# --- contracts and settings ---------------------------------------------------
pydantic==2.13.4
pydantic-settings==2.12.0

# --- database -----------------------------------------------------------------
# `binary` so the image needs no libpq build chain; `pool` because
# provenance_db.retry takes an AsyncConnectionPool.
psycopg[binary,pool]==3.3.4

# --- models -------------------------------------------------------------------
# The Google agent framework the agent layer is written against.
# CANONICAL_DECISIONS.md -> Gemini model id canon.
google-genai==1.60.0

# --- MCP ----------------------------------------------------------------------
# app/mcp/server.py subclasses FastMCP.
mcp==1.21.2

# --- identifiers --------------------------------------------------------------
# provenance_contracts.base falls back to uuid4 when no uuid7 is available, and
# says so through UUID_GENERATOR. The fallback is correct but not free:
# CockroachDB splits ranges lexicographically on the primary key, so scattered
# ids scatter an append-heavy table. Declared rather than left to chance.
uuid6==2024.7.10
